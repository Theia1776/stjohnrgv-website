## Library migration — status & how to continue

**Goal:** move the parish's external MEGA book library (50+ books, multi-GB) into
the site's Supabase library, landing each in the **Hidden** tier first, then
promoting to Parishioners/Public from /admin/library "as needed." Preservation +
curation.

**Done so far: 214 books staged Hidden** (Patristics 81, Hagiography 44,
Theology/Doctrine 29, History 28, Scripture 15, Spiritual Life 15, Liturgical 2).
- Batch 1 = "Books on Church History" (38) → metadata [scripts/library-batch1.json](../scripts/library-batch1.json).
- Batch 2 = a large Patristics/Theology/Scripture set (109) → metadata [scripts/library-batch2.json](../scripts/library-batch2.json).
- Batch 3 = St. Philaret parish cookbook (1, category Other) → [scripts/library-batch3.json](../scripts/library-batch3.json).
- Batch 4 = "Lives of the Saints" (~2 GB; 67 uploaded, 7 dup-pairs collapsed, 8 too-big) → [scripts/library-batch4.json](../scripts/library-batch4.json). **Total now 214.** The uploader gained an optional 4th CLI arg = default category for files with no metadata entry (used `Hagiography` for this batch).

### To upload the NEXT batch
1. Tina drops the batch's PDFs into **`library-incoming/`** in the project folder
   (git-ignored, always accessible to the agent), or any local folder she names.
2. Agent lists the PDFs + sizes, writes `scripts/library-batchN.json` with
   `{file, title, author, category, description}` per book (category must be one
   of: Hagiography, Liturgical Texts, Patristics, Scripture, History,
   Theology / Doctrine, Spiritual Life, Other).
3. Run the uploader (reads the key from `scripts/service-role.txt`):
   ```
   node scripts/bulk-upload-library.mjs "<folder>" scripts/library-batchN.json
   ```
   It stages everything as **Hidden**, is **idempotent** (skips books whose slug
   already exists), skips files **>50 MB** and 0-byte files, and falls back to a
   filename-derived title if a PDF has no metadata entry (so nothing is dropped).
4. **Watch for title collisions:** slugs are derived from the title, so two
   *different* books with the same short title collide (the 2nd is skipped as
   "already in catalog"). Fix by making the titles unique (add the author) and
   re-run — only the renamed ones get added.
5. Tina promotes books from /admin/library when ready.

## 2. Domain Evaluation Criteria

Each candidate domain is scored on five criteria (1–5 scale each, 25 points total):

| Criterion | Weight | Description |
|---|---|---|
| **Local SEO signal** | 5 | Does it contain RGV/South Texas geographic identifiers? |
| **Parish identity** | 5 | Does it identify St. John of Kronstadt specifically? |
| **Memorability** | 5 | Is it short, pronounceable, and easy to remember? |
| **Extension appropriateness** | 5 | Is `.org` used? (preferred for churches) |
| **Availability likelihood** | 5 | Likely to be unregistered and available? |

## 6. Domain Migration Plan

### Pre-Migration Checklist
- [ ] New domain `stjohnrgv.org` registered and confirmed
- [ ] New site fully built and tested on the new domain
- [ ] All pages have correct canonical URLs pointing to `stjohnrgv.org`
- [ ] Schema.org markup updated to `stjohnrgv.org`
- [ ] Google Analytics 4 property updated
- [ ] Google Search Console: new property added for `stjohnrgv.org`
- [ ] Google Business Profile: website URL updated to `stjohnrgv.org`

### Migration Steps

**Step 1: Set up 301 Redirects**  
On the old WordPress host (orthodoxtexas.com), add 301 permanent redirects:
```
orthodoxtexas.com/ → stjohnrgv.org/
orthodoxtexas.com/about/ → stjohnrgv.org/about/
orthodoxtexas.com/schedule/ → stjohnrgv.org/schedule/
orthodoxtexas.com/contact/ → stjohnrgv.org/contact/
orthodoxtexas.com/announcements/ → stjohnrgv.org/announcements/
```
Or use a catch-all redirect:
```
orthodoxtexas.com/* → stjohnrgv.org/$1
```
This tells Google that the old domain has permanently moved and transfers any existing ranking signals.

**Step 2: Deploy New Site**  
Deploy the new static site to Netlify or Vercel and point `stjohnrgv.org` to the new host.

**Step 3: Update Google Search Console**  
1. Add `stjohnrgv.org` as a new property in Google Search Console
2. Submit the new sitemap: `https://stjohnrgv.org/sitemap.xml`
3. In the old `orthodoxtexas.com` property, use the "Change of Address" tool to notify Google of the migration

**Step 4: Update All External References**
- [ ] Orthodox Metropolia parish listing — update to new URL
- [ ] Avlona Synod USA directory — update to new URL
- [ ] NFTU (nftu.net) — request update if listed
- [ ] IPC Katakomb (ipckatakomb.ru) — update any cross-links
- [ ] Google Business Profile — update website URL
- [ ] All printed materials (bulletins, business cards) — plan for reprinting

**Step 5: Monitor Migration**
- Check Google Search Console daily for the first 2 weeks post-migration
- Verify 301 redirects are working (test with browser and redirect checker tools)
- Monitor organic traffic in Google Analytics — expect a temporary small dip, recovering within 4–8 weeks
- Confirm new domain is indexed: search `site:stjohnrgv.org` in Google

### Migration Timeline

| Week | Action |
|---|---|
| Week 1 | Register new domain; build site on new domain |
| Week 2–4 | Complete new site build and testing |
| Week 4 | Set up 301 redirects on old domain |
| Week 4 | Deploy new site; update GBP, Search Console |
| Week 5–6 | Update all external directory listings |
| Week 6–12 | Monitor rankings and traffic; verify redirects |
| Month 3+ | Begin letting orthodoxtexas.com lapse OR keep for perpetual redirect |

## 8. SSL / HTTPS

All modern hosting platforms (Netlify, Vercel, Cloudflare Pages) issue free SSL certificates automatically via Let's Encrypt. No action required beyond deploying the site.

Ensure:
- All internal links use `https://` (no mixed content)
- HTTP → HTTPS redirect is automatic (enabled by default on Netlify/Vercel)
- HSTS header is set (Netlify enables this automatically)

---

## 9. Long-Term Domain Strategy

### Keep `orthodoxtexas.com` as a Redirect
Recommendation: Renew `orthodoxtexas.com` for at least **2–3 years** after migration and keep the 301 redirect active. This:
- Ensures anyone who bookmarked or linked to the old domain still reaches the site
- Preserves any residual domain authority transfer
- Costs only ~$13/year

After 3 years, evaluate whether to renew based on traffic data from Google Analytics (zero traffic from old domain = safe to let lapse).

### Register Defensive Domains
Consider registering these to prevent squatting or confusion:
- `stjohnkronstadt.org` — brand protection
- `orthodoxrgv.org` — future use / redirect

All can redirect to `stjohnrgv.org` immediately after registration.
